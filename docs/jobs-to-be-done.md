# Jobs To Be Done

Each job describes what the person needs to accomplish independent of Calcify or any specific screen, control, or feature.

| ID | Role | Job | JTBD statement |
| --- | --- | --- | --- |
| J1 | Everyday User | Get a quick numerical answer | When I need to work out a number during an everyday task, I want to calculate it quickly and accurately, so I can make a decision or continue what I am doing without working it out manually. |
| J2 | Everyday User | Understand an unfamiliar value | When I encounter a measurement or currency amount in an unfamiliar form, I want to understand its equivalent in a form I recognize, so I can compare values and use the information confidently. |
| J3 | Everyday User | Refer back to recent work | When I am working through several related calculations, I want to refer back to results I just obtained, so I can avoid repeating work and maintain context. |
| J4 | Student / Technical User | Solve a more advanced mathematical problem | When I am working on a mathematical, scientific, or technical problem, I want to evaluate more advanced expressions accurately, so I can continue solving the problem with confidence. |
| J5 | Student / Technical User | Correct or refine part of a calculation | When I notice that one part of a calculation needs to change, I want to adjust only that part, so I can recalculate efficiently without starting over. |
| J6 | Everyday User | Understand a future borrowing commitment | When I am considering a loan or financing option, I want to estimate the regular payment, so I can judge whether the commitment may fit my budget. |

## Role-to-Job Traceability

| Role | Jobs |
| --- | --- |
